scanspy 详细使用文档

Windows x64 命令行工具 | 更新日期 2026-09-10

本工具检测 PDF 的页面结构，并以 JSON 返回文档类型及业务判断标记。适用于本地文件、PDF 直链及批量调用；本工具不执行 OCR。

本次业务规则

混合扫描件 MIXED_SCANNED 的 scanned 已改为 false。只有纯扫描件 SCANNED 返回 true。type 和页数统计继续返回实际检测结果。

文档类型 typescanned含义
STANDARDfalse当前规则未识别到扫描页。
MIXED_SCANNEDfalse存在扫描页，同时存在可提取文字。
SCANNEDtrue存在扫描页，且文档中没有可提取文字。

运行要求和交付文件

面向 Windows 10 / Windows 11 的 64 位环境。用户无需安装 Python 或项目依赖。请在 PowerShell 或 CMD 中运行；直接双击不会显示文件选择窗口。

快速开始

在 PowerShell 中运行以下命令，并将路径替换成实际位置：

& "C:\tools\scanspy\scanspy.exe" "C:\input\file.pdf"

判断文件类型前，先确认 code=200 且 success=true。scanned=false 本身不能代表处理成功。

运行方法

PowerShell

EXE 和 PDF 路径均建议使用英文双引号。以引号包裹 EXE 完整路径时，前面使用调用运算符 &。

& "C:\tools\scanspy\scanspy.exe" "C:\input\file.pdf"

& "C:\tools\scanspy\scanspy.exe" "https://example.com/file.pdf"

& "C:\tools\scanspy\scanspy.exe" "C:\input\a.pdf" "C:\input\b.pdf"

如果当前目录就是 EXE 所在目录，可直接使用：

.\scanspy.exe "C:\input\file.pdf"

CMD

CMD 中不使用 PowerShell 的 & 调用运算符：

"C:\tools\scanspy\scanspy.exe" "C:\input\file.pdf"

输入限制

1. 本地输入必须是 .pdf 文件路径，不接受 DOCX 或目录。文件名后缀不区分大小写。

2. 网络输入必须是 http:// 或 https:// 地址，URL 的路径部分以 .pdf 结尾，返回内容应为可读取的 PDF。网页预览地址不能直接使用。

3. 多个输入依次处理；data 数组与输入顺序对应，一个文件处理失败不会丢弃其他文件的结果。

网络文件与临时目录

PDF 直链会先下载到系统 %TMP% / %TEMP% 下的 scanspy-* 临时目录，再进行检测。正常结束或解析报错后会清理该临时目录。网络请求使用 20 秒超时设置；这不是整份 PDF 检测的总耗时上限。

输出和进程退出码

标准输出打印一行 UTF-8 编码的 JSON。所有输入处理成功时，进程退出码为 0；参数错误或任意输入处理失败时为 1。纯扫描件也可以处理成功并返回退出码 0，业务系统仍需读取 scanned。

JSON 字段说明

成功和失败结果的 data 均为数组。每个结果项的字段顺序和结构一致，方便按 R<List<ScanDetectResult>> 读取。以下 code 为 JSON 内的状态字段。

字段位置说明
code外层及结果项200 表示处理成功，400 表示处理失败。
success外层及结果项处理是否成功。批量调用需同时检查每个结果项。
data外层按输入顺序排列的结果数组。
source结果项原始输入路径或 URL。
fileName结果项文件名。
fileSize结果项文件大小，单位为字节。
suffix结果项文件后缀；成功的 PDF 输入为 PDF。
scanned结果项仅 SCANNED 为 true；STANDARD 和 MIXED_SCANNED 为 false。
type结果项文档类型；保留混合扫描件的细分信息。
confidence结果项固定为 0.0。当前结构规则不生成统计置信度。
pageCount结果项PDF 实际总页数。
scannedPages结果项当前结构规则识别为扫描页的数量。
textPages结果项存在可提取文字的页数，包含页眉页脚或页码文字。
sourceType结果项FILE、URL 或 UNKNOWN。
msg外层中文结果说明。失败详情读取此字段。
errorCode外层错误码；成功时为空字符串。

同一页可以同时计入 scannedPages 和 textPages，因此两项之和可能大于 pageCount。处理失败时页数通常为 0，不能作为成功检测的统计结果。

返回示例与分类解释

以下为两页混合 PDF 的完整返回格式示例。示例文件名、大小及页数仅用于说明字段，实际输出以输入文件为准。

{
  "code": 200,
  "success": true,
  "data": [
    {
      "code": 200,
      "success": true,
      "source": "C:\\input\\mixed.pdf",
      "fileName": "mixed.pdf",
      "fileSize": 12345,
      "suffix": "PDF",
      "scanned": false,
      "type": "MIXED_SCANNED",
      "confidence": 0.0,
      "pageCount": 2,
      "scannedPages": 1,
      "textPages": 1,
      "sourceType": "FILE"
    }
  ],
  "msg": "操作成功",
  "errorCode": ""
}

类型如何理解

STANDARD 表示当前规则未识别出扫描页，不保证文档中完全没有图片。空白页不影响文档类型，完全空白的 PDF 按 STANDARD 处理。

MIXED_SCANNED 表示存在扫描页且文档中存在可提取文字。文字页与扫描页混排、扫描页带 OCR 文字层，以及仅有可提取页眉页脚文字等情况，都可能归入混合扫描件；新版统一返回 scanned=false。

SCANNED 表示识别到扫描页且没有可提取文字，新版继续返回 scanned=true。EMPTY 为兼容保留类型，当前规则不主动返回；UNKNOWN 通常表示处理失败。

错误处理

请先检查处理状态，再应用 scanned 业务规则。失败结果也使用统一字段结构，type=UNKNOWN、scanned=false；这表示未完成有效判断，不能当作普通 PDF 放行。

errorCode说明与处理建议
INVALID_ARGUMENT未传参数、后缀不正确、URL 不符合要求等。核对命令与输入。
PARTIAL_FAILURE批量输入中至少一个文件失败。逐项检查 data 中的 code 和 success。
PDF_NOT_FOUND本地文件不存在。检查路径和文件名。
PDF_NOT_FILE路径不是普通文件，例如传入了目录。
PDF_DOWNLOAD_ERROR网络请求失败、超时或返回非成功状态。检查网络和 PDF 直链。
PDF_URL_NOT_PDFURL 响应内容不是 PDF；URL 路径后缀错误通常属于 INVALID_ARGUMENT。
PDF_PARSE_ERRORPDF 无法解析。检查文件是否损坏或不可读取。
PDF_EMPTY兼容保留错误码；当前处理流程不主动抛出此错误。

批量调用

部分失败时，外层 code=400、success=false、errorCode=PARTIAL_FAILURE，但 data 仍保留所有输入的结果。成功文件的结果项 code=200；失败文件的结果项 code=400。失败详情位于外层 msg 和 errorCode。

接入顺序

1. 确认程序正常结束并且输出可以解析为 JSON。

2. 读取外层及各结果项的 code、success；对处理失败的文件按错误流程处理。

3. 对处理成功的结果读取 scanned。true 按纯扫描件处理；false 按本次业务约定处理，并保留 type 供详情展示。

替换与复核

替换旧版本

1. 确认业务系统实际调用的 scanspy.exe 完整路径，将本次交付的新 EXE 替换到该位置。保留现有命令行参数和 JSON 读取方式。

2. 若系统提示文件被占用，等待正在运行的检测进程结束后再替换。

3. 将本次 README 和 PDF 使用文档一并替换，避免继续参照旧版本中混合扫描件返回 true 的说明或旧截图。

统计和业务边界

scannedPages 是结构规则的命中数，不等于人工确认的扫描附件数量。textPages 统计任何可提取文字，不保证正文都有文字层。scanned=false 也不能直接说明文档无需 OCR。

本工具不判断营业执照、资质证书、合同等附件是否满足投标要求；附件内容的审核由业务系统承担。当前接口不返回逐页页码列表。

本次更新对应关系

混合扫描件的业务布尔值由 true 调整为 false；文档细分类型、实际总页数和页级计数继续保留。本版说明已更新页数统计口径，并移除了旧 OCR 接口映射和旧输出截图。
