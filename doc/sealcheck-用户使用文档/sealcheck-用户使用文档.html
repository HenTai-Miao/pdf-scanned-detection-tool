sealcheck Windows 命令行工具用户使用文档

sealcheck.exe 是独立 CLI，只用于快速判断 PDF 中是否存在签章。它不和 scanspy.exe 打包在一起，也不做证书验签、不判断文件是否被篡改、不返回签章页码明细。

独立 EXE支持多个 PDF支持 PDF 直链 URLJava JSON 友好

快速说明

输入一个或多个本地 PDF 路径，或者一个或多个以 .pdf 结尾的 HTTP/HTTPS 直链。
输出标准输出打印一行 JSON，外层固定为 code/success/data/msg/errorCode。
判断规则只要 PDF 内存在至少 1 个签章字段、签章控件或签名对象，就返回 hasSignature=true。
本工具适合做“有没有签章”的快速检查。需要验签、签名有效性、完整性或签章明细时，请使用 signspy。

命令格式

推荐在 PowerShell 中使用完整路径调用 exe。PDF 路径外层加英文双引号，避免中文、空格或括号导致命令解析错误。

C:\tools\sealcheck\sealcheck.exe "C:\Users\xxx\Desktop\a.pdf" C:\tools\sealcheck\sealcheck.exe "C:\Users\xxx\Desktop\a.pdf" "C:\Users\xxx\Desktop\b.pdf" C:\tools\sealcheck\sealcheck.exe "https://example.com/a.pdf"

返回字段

字段位置说明
code外层 / data itemHTTP 风格状态码。成功通常是 200；参数错误或处理失败通常是 400。
success外层 / data item是否成功。多个 PDF 中有任意一个失败时，外层会返回失败或部分失败。
data外层数组，每个输入对应一个检测结果。
sourcedata item原始输入，本地路径或 URL。
fileNamedata item文件名，例如 a.pdf。
fileSizedata item文件大小，单位 byte。URL 输入会返回下载后的文件大小。
suffixdata item文件后缀，当前要求为 PDF。
hasSignaturedata item核心字段。true 表示检测到至少 1 个签章标记；false 表示没有检测到签章标记。
sourceTypedata item输入来源：FILE、URL 或 UNKNOWN。
msg外层中文提示信息。
errorCode外层错误码。成功时为空字符串。

错误说明

错误码含义常见原因
INVALID_ARGUMENT参数错误未传入参数，或输入不是 .pdf 文件 / .pdf 直链。
PDF_NOT_FOUND文件不存在本地 PDF 路径不存在。
PDF_NOT_FILE不是文件传入的是目录或非普通文件。
PDF_DOWNLOAD_ERROR下载失败URL 网络不可达、超时或状态码异常。
PDF_URL_NOT_PDFURL 不是 PDFURL 后缀不是 .pdf，或响应内容不是 PDF。
PDF_PARSE_ERRORPDF 解析失败PDF 损坏、加密不可读或底层库无法解析。
PARTIAL_FAILURE部分失败一次传入多个 PDF，其中至少一个处理失败。
